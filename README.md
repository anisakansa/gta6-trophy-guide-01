Leonida Trophy Atlas is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every official name, description and grade, a guide in plain words for each trophy, a checklist that saves in your browser with export and import, filters by kind and grade, a spoiler setting that hides story trophies until earned, and a six-stage roadmap to the platinum with the one missable trophy flagged.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network needed. Or open `app/index.html` directly in a desktop browser.
